# ❤️ Organ Donator and Finder Website

## 📌 About the Project

Organ Donator and Finder is a website project designed to demonstrate donor and receiver registration interfaces and promote awareness about organ donation.

## 🎯 Project Objectives

* Provide separate registration forms for donors and receivers.
* Collect basic form information for demonstration purposes.
* Display registration details after form submission.
* Show sample hospital information.
* Demonstrate email notifications using EmailJS.

## ✨ Features

* Home page with Donor and Receiver options.
* Donor registration form.
* Receiver registration form.
* Declaration form.
* Registration details display.
* Sample hospital information.
* Email notification integration.
* Responsive design for desktop and mobile screens.

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* EmailJS

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Complete the donor or receiver form to explore the website.

## 📧 Email Integration

EmailJS is used to demonstrate sending application notification emails to the email address entered by the user.

Email functionality requires valid EmailJS configuration.

## ⚠️ Disclaimer

This project is intended for educational and demonstration purposes only.

The hospital information and appointment details displayed are illustrative. This website is not connected to an actual hospital, organ donation registry, or transplant allocation system.

Do not enter real Aadhaar numbers, passwords, prescriptions, or sensitive medical information.
